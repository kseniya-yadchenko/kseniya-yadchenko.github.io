# Research: хостинг + домен для персонального сайта

Дата: 2026-08-26. Все цены — публичные тарифы на эту дату.

---

## 0. Главный вопрос: «полноценное фронтенд-приложение или только HTML?»

Тут смешаны три разные вещи. Разведём их, потому что от этого зависит выбор хоста.

| Что именно                                                                                    | Что это технически                                                                                 | Кто умеет                                                                                      |
| --------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| **1. Один HTML-файл**                                                                         | `index.html` + CSS/JS внутри. Никакой сборки.                                                      | Все до единого.                                                                                |
| **2. Полноценное фронтенд-приложение** (React / Vue / Svelte / Astro, сборка через Vite)      | После `npm run build` это **всё равно набор статических файлов** — HTML, JS, CSS. Сервер не нужен. | **Все до единого.** Это ключевой момент: «полноценный фронтенд» ≠ «нужен сервер».              |
| **3. Серверная часть** — SSR, API-роуты, база данных, приём формы обратной связи, авторизация | Нужен исполняемый код на стороне сервера (Node / Workers / serverless-функции).                    | Только Cloudflare Workers, Vercel, Netlify, VPS. **GitHub Pages и объектные хранилища — нет.** |

**Вывод:** ограничение «только HTML» не существует нигде из рассмотренного. Реальная граница проходит по пункту 3. Для этого сайта пункт 3 нужен ровно в одном месте — форма «написать мне», и её можно закрыть либо `mailto:`, либо сторонним сервисом форм.

## 1. Зарубежные платформы

### Cloudflare Pages / Workers Static Assets

- **Free:** неограниченный трафик и количество запросов, 500 сборок/мес, 1 параллельная сборка, до 20 000 файлов в деплое, 25 MiB на файл, 100 доменов на проект, неограниченные preview-деплои, бесплатный SSL.
- **Что можно запускать:** статику, любой собранный SPA, **и полноценный SSR** через Workers (Next.js через OpenNext, Astro, Nuxt, SvelteKit), serverless-функции, БД D1, хранилища KV/R2.
- **Платно:** Workers Paid — $5/мес, нужен только если упрёшься в лимиты серверных функций. Для этого сайта — не нужен.
- **Коммерческое использование:** разрешено, отдельного запрета нет.
- ⚠️ **Риск:** с 2026 года часть IP-диапазонов Cloudflare в России фильтруется через DPI — сайты за Cloudflare у части российских провайдеров открываются медленно или не открываются. Формально это не блокировка, а замедление, но эффект для читателя тот же.

### Vercel

- **Hobby (free):** 100 GB трафика, 1 млн edge-запросов, 1 млн вызовов функций, 100 деплоев/день, 50 доменов на проект.
- **Что можно запускать:** всё, включая Next.js SSR/ISR/API-роуты. Лучший DX для Next.js.
- ⚠️ **Ключевая проблема:** тариф Hobby по ToS **разрешён только для личного некоммерческого использования**. Сайт с разделами «Для редакций» и «Перевод» — это продвижение платных услуг. Формально это уже commercial use → Pro **$20/мес**.
- ⚠️ Тот же риск доступности из РФ.

### Netlify

- **Free:** 300 кредитов/мес. Расход: 20 кредитов за GB трафика (≈ **15 GB/мес**), 15 кредитов за production-деплой (≈ **20 деплоев/мес**). Отправка форм — бесплатно, кредиты не тратит.
- По сообщениям вторичных источников (официально не подтверждено): при исчерпании кредитов на free-тарифе сайт **ставится на паузу** до следующего месяца.
- **Personal** — $9/мес (1000 кредитов), **Pro** — $20/мес (3000 кредитов).
- **Что можно запускать:** статику, SPA, SSR, serverless-функции. Плюс — **бесплатные формы из коробки**, это единственный хост в списке, который решает «форму обратной связи» без стороннего сервиса.
- ⚠️ Кредитная модель (введена в сентябре 2025, доработана в апреле 2026) делает бесплатный тариф непредсказуемым. Для сайта-визитки 15 GB хватит с запасом, но 20 деплоев в месяц — это мало, если активно править.

### GitHub Pages

- **Free**, оплата не нужна вообще. 1 GB на сайт, ~100 GB/мес трафика (мягкий лимит), 10 сборок/час (мягкий лимит), кастомный домен и бесплатный HTTPS.
- **Что можно запускать:** **только статику.** Никакого серверного кода, никаких serverless-функций, никаких redirect-правил и кастомных HTTP-заголовков. Собранный SPA работает, но клиентский роутинг требует костыля с `404.html`.
- ⚠️ **ToS:** прямо запрещено использовать как бесплатный хостинг «для ведения онлайн-бизнеса или e-commerce». Портфолио с описанием услуг — обычно нормально; приём платежей — нет.
- ⚠️ Доступность GitHub в России ухудшается с мая 2026 (доля сбоев выросла с 4% до 10–16%); РКН блокировку отрицает, но выборочные обрывы есть.

## 2. Российские и белорусские варианты

Смысл: оплата местной картой в местной валюте, без санкционных проблем, и гарантированная доступность для русскоязычного читателя.

| Провайдер                       | Цена                                                                                                                                    | Что можно запускать                                                 |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **hoster.by**                   | Единственный ICANN-аккредитованный регистратор в Беларуси. Регистрирует `.by` и международные зоны, серверы в Беларуси, 14 дней триала. | Shared: статика + PHP. Node/SSR — только на VDS.                    |
| **Timeweb / Timeweb Cloud**     | Виртуальный хостинг от 180 ₽/мес (при оплате за 3 года) / 393 ₽/мес помесячно. VDS от 450 ₽/мес. Домены `.ru`/`.рф` от 179 ₽.           | Shared: статика + PHP. VDS: что угодно, включая Node SSR.           |
| **Beget**                       | от ~300 ₽/мес.                                                                                                                          | То же самое.                                                        |
| **Yandex Cloud Object Storage** | Оплата по факту, для сайта-визитки — копейки в месяц. Статический хостинг + бесплатные DNS/SSL.                                         | **Только статика.** Серверный код — через Cloud Functions отдельно. |

⚠️ Обратная сторона: для международного читателя (редакции, к которым она пишет) это медленнее, и `.by`/`.ru`-зона выглядит менее нейтрально в англоязычном контексте.

## 3. Домены

### Cloudflare Registrar — по себестоимости, без наценки

Цены = оптовая цена реестра + $0.18 сбора ICANN. Регистрация и продление совпадают (кроме отмеченных).

| Зона      | Регистрация | Продление |
| --------- | ----------- | --------- |
| `.com`    | $10.46      | $10.46    |
| `.net`    | $11.86      | $11.86    |
| `.org`    | $8.50       | $11.20    |
| `.me`     | $16.56      | $16.56    |
| `.dev`    | $12.20      | $12.20    |
| `.page`   | $10.20      | $10.20    |
| `.link`   | $7.20       | $7.20     |
| `.xyz`    | $12.30      | $11.20    |
| `.blog`   | $20.20      | $20.20    |
| `.info`   | $21.20      | $21.20    |
| `.site`   | $27.70      | $27.70    |
| `.co`     | $30.00      | $30.00    |
| `.studio` | $31.20      | $31.20    |
| `.world`  | $32.20      | $32.20    |
| `.io`     | $50.00      | $50.00    |

WHOIS-приватность и DNSSEC включены бесплатно. Всего поддерживается 417 зон.

⚠️ **Важное ограничение:** домен, зарегистрированный в Cloudflare Registrar, **обязан использовать NS-серверы Cloudflare**. Перенести DNS к другому провайдеру нельзя — только вместе с трансфером домена, и то через 60 дней после регистрации. Для нашего сценария это не мешает, но знать надо.

### Porkbun — альтернатива

`.com` $9.73 (с 1 ноября 2026 поднимется до ~$11.81), `.net` $11.52, `.dev` $12, `.io` $32.37. Бесплатно: WHOIS-приватность, SSL, форвардинг почты и URL, DNSSEC. DNS можно держать где угодно.

### Российские / белорусские регистраторы

- **reg.ru:** `.ru`/`.рф` — 169 ₽ регистрация (акция на весь 2026), 1199 ₽ продление. Международные зоны дороже Cloudflare, но оплата местной картой.
- **hoster.by:** `.by` и международные зоны, оплата в BYN.

⚠️ **Главный практический вопрос:** Cloudflare, Porkbun, Vercel и Netlify требуют карту, выпущенную за пределами РФ/РБ. Российские и белорусские карты у них не проходят с 2022 года. Это, а не техника, чаще всего и определяет выбор.

| Собранный SPA                | ✅                | ✅          | ✅             | ✅ (с костылём)    | ✅                  |
| SSR / API / БД               | ✅                | ✅          | ✅             | ❌                 | только VDS          |

| Домен рядом                  | **$10.46 (.com)** | ~$20        | ~$20           | нет                | 169 ₽ (.ru)         |
| Оплата картой РФ/РБ          | ❌                | ❌          | ❌             | не нужна           | ✅                  |
| Доступность из РФ            | ⚠️ DPI-фильтрация | ⚠️          | ⚠️             | ⚠️ сбои с мая 2026 | ✅                  |

**Рекомендация по умолчанию:** Cloudflare Pages + домен `.com` в Cloudflare Registrar. Итого **$10.46/год и больше ничего** — хостинг, безлимитный трафик, SSL, CDN и запас на будущее (можно дорастить до SSR и API, не переезжая). Единственные два «но» — нужна не-РФ/РБ карта и риск замедления для российских читателей.

**Если нет международной карты** → GitHub Pages ($0, оплата не нужна вообще) для хостинга + домен через reg.ru местной картой. Ограничение — только статика, но для этого сайта этого достаточно.

**Если российская аудитория критична** → добавить зеркало на Yandex Cloud Object Storage или сразу хостить на Timeweb.
